# Rajshalem5.github.io

The interactive version of my GitHub profile: https://rajshalem5.github.io

One static HTML file, no dependencies, no build step, no tracking. Every number on
the page comes from the GitHub API at build time and is embedded as JSON.

## What is in it

- **Console** — twelve real controls, each wired to something on the page: a live
  search, a described-repos filter, three sort modes, a scrubber across 368 days of
  contributions, a surge progress bar, a browser-local bookmark, copy-email, tabs,
  and a motion switch that turns every effect off.
- **Motion** — spring overshoot on transforms, and a canvas layer that draws impact
  bursts and slashes on click. No manga lettering: this page is read by people who
  hire.
- **Reduced motion** — the switch in the console is the control. It is not forced on
  by the OS setting, so the effects you came for are still there by default.

## Regenerating the data

`index.html` embeds a `DATA` object: an array of daily contribution counts and an
array of public repos. The profile cards in
[Rajshalem5/Rajshalem5](https://github.com/Rajshalem5/Rajshalem5) are generated by
that repo's `assets/generate.py` from the same source.
